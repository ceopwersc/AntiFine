## Architecture and contracts

The backend now separates authorization/serialization, core/integration routes, private workspaces, isolated scan execution, versioned persistence, deterministic remediation and webhook transport. The existing optional advisory endpoints remain composed in `server.py`. Frontend workflow components and hooks share a typed finding contract and reload backend evidence. This is a focused separation of trust boundaries, rather than a new application framework.

Rule IDs are explicit constants. File IDs and finding IDs derive from canonical identities; display redaction cannot choose a source file. A preview binds a persisted finding to exact source bytes and resource location. Automatic edits are deliberately limited to parsed RDS public-access and Kubernetes privilege booleans. Shared source anchors, unknown structures and unsupported fixes fail closed. An applied fix is `verified` only after complete deterministic scanning finds no remaining finding; other remaining findings produce an applied but unverified result.

Schema v3 adds scan runs, coverage, immutable per-run evidence and finding identity/source fields. Migration is additive for structural/history/mapping data. The privacy pass deliberately changes unsafe legacy display values and disables credential-bearing URLs; it does not reconstruct compliance mappings. SQLite secure deletion clears replaced cell content in the migrated database. Tests exercise a synthetic legacy database, not the developer database.

## Remaining limits and unverified environments

- Remote GitHub CI was configured but not run from this session. Linux and Python 3.12 results are pending that workflow; the local results above establish Windows/Python 3.14 only.
- The Windows account cannot create symbolic links, so that one test is visibly skipped. A real Windows directory junction test passes. POSIX symlink behavior awaits Linux CI.
- Live Ollama inference and actual external webhook delivery were not exercised. Security tests mock model responses and DNS/transport without external deliveries. Ollama remains optional/advisory.
- Static IaC checks do not evaluate all Terraform expressions/plans/providers, every Docker runtime behavior, full Kubernetes PSS or a complete CIS/PCI framework. Mappings do not establish certification. PDF export is absent.
- Docker automatic user creation and fabricated healthchecks are intentionally unsupported/manual-only. Ambiguous/shared-source remediation is also manual-only. Immutable backup quota exhaustion requires operator archival before another fix.
- Path revalidation, bounded reads, locks and atomic writes reduce races; they are not a formal sandbox against an administrator or hostile process with the same OS account. Run the workstation locally under a trusted account. Public/reverse-proxy deployment is unsupported.
- Redaction is conservative pattern/context handling, not proof that every arbitrary hostile string is non-secret. Preserve the centralized fail-safe boundaries when adding fields or transports. Private original sources/backups necessarily retain source bytes on the local filesystem.
- Dependency checks report the installed ecosystem state, not a guarantee against future vulnerabilities. Two installed TestClient/AnyIO deprecation warnings remain visible; no security rule or warning was suppressed to pass tests. Recharts 2.x emits an install deprecation notice but has no reported npm audit vulnerability in this run.
