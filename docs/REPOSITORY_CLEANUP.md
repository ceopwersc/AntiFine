## Scope and safeguards

The initial inventory contains 153 tracked files. No tracked dependency tree, virtual environment, real database, credential file, or build directory was found. The generated reports above are removed only from future Git trees; their local originals and historical commits remain. No operational credential was identified in the reviewed tracked report artifacts; this cleanup does not rewrite history or establish a historical secret audit.

Deletion is limited to named candidates, with resolved paths verified beneath the checkout, no reparse traversal, and contents rechecked immediately before removal. There is no blanket `git clean`, hard reset, removal of user projects, or test suppression. Unknown/ambiguous files are retained.
